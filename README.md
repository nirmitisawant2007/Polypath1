 ✨ Features
- 🔐 User Authentication: Firebase-powered Signup and Login with strict password validation.
- 📅 Academic Calendar: Stay updated with important academic schedules and events.
- 📢 Announcements & FAQs: Important updates and quick solutions for common doubts.
- 🤖 Chatbot Assistance: In-app AI/Interactive Chatbot to answer student queries.
- 📚 Syllabus & Manuals: Easy access to course curriculum and lab manuals.
- 📝 Exam Forms & Feedback: Streamlined access to academic feedback and form submissions.

---

🛠️ Tech Stack & Tools
- Language: Java
- IDE: Android Studio
- Backend / Database: Firebase Authentication & Realtime Database
- UI Design: XML, Material Design Components
